# Datos reales preparados localmente

`dbpedia/` se genera con `python3 scripts/prepare_real_dataset.py` desde la raíz
del repositorio. Contiene el catálogo, las consultas y la procedencia; se excluye
de Git por su tamaño. Consultar [el caso real](../../docs/real_world_validation.md)
para la fuente, el esquema, el uso y la validación independiente.
